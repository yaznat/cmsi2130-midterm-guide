# cmsi2130-midterm-guide

Resources for the CMSI 2130 midterm

## Exam Logistics

- **Duration:** 90 minutes
- **Style:** conceptual, **no programmatic components**
- **Resources:** allowed ONE 8.5" x 11" cheet sheet (double sided OK)

## Question Types

Exam format may include:
- Definitions and short answer questions
- Multiple choice
- Tracing execution of search strategies in classical search problems and on abstract search trees
- Tracing execution of minimax and $\alpha$-$\beta$ pruning algorithms in an abstract game tree
- Tracing execution of dynamic programming deployed to solve problems with optimal substructure
- Applying paradigms we've learned in ways we **haven't seen** in class
